# House Intelligence

A Home Assistant intelligence layer for discovering, understanding, and improving whole-home systems.

## Vision

House Intelligence builds a whole-home model from Home Assistant entities, devices, areas, and historical data. It aims to identify relationships, detect abnormal behavior, and provide useful insights while keeping existing integrations independent.

## Initial principles

- Read-only discovery first
- Keep Heating Intelligence independent
- Discover and classify entities automatically
- Minimize exposed entities; aggregate insights centrally
- Validate findings against actual Home Assistant data
